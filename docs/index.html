opensync-lab

A reproducible, one-command lab for an OpenSync-enabled containerized RDK-B gateway (the LGI mv3), with three OpenSync extenders built from the open-source release, six wireless clients, and local-noc, a local stand-in for the OpenSync cloud that records the whole protocol and draws the network live.

Three stages, three scripts

stage 1

build-mvx.sh

A fresh, pinned, offline build of the mv3 LXD image that reproduces the reference build package for package.
stage 2

setup-vm.sh

An isolated LXD VM with boardfarm's WAN side, nested LXD, a hwsim radio pool, local-noc and the view on the host.
stage 3

deploy-mvx.sh

Launch mv3, check the WAN, connect OpenSync to Plume or local-noc, build and check the 3-extender topology.

Quick start

# 1. the mv3 image: fresh checkout pinned to the reference build, offline
./build-mvx.sh pin && ./build-mvx.sh build
# the extender image (OpenSync 6.6.1.0)
./build-pod.sh all
# 2. the lab VM: boardfarm WAN side, nested LXD, hwsim pool, local-noc
./setup-vm.sh all
# 3. deploy: mv3 + WAN check + OpenSync (Plume)
./deploy-mvx.sh all
# the extender topology on local-noc: 3 pods x 2 clients + topology check
./deploy-mvx.sh mesh
# watch it
./setup-vm.sh status        # prints http://<host>:8640/

Settings live in config/mvx.conf and can be overridden from the environment; values the scripts must remember (VM name, build dir, pod image) go to the untracked config/local.conf. See the reference.
